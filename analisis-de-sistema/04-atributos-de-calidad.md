# Atributos de calidad del Marketplace

Durante una campaña comercial, muchos usuarios pueden consultar productos
y realizar compras simultáneamente. El sistema debe mantener un
comportamiento adecuado frente a esta demanda.

| ID | Atributo de calidad | Descripción |
|----|---------------------|-------------|
| AC01 | Rendimiento | Las consultas de productos y las operaciones del carrito deben responder rápidamente, incluso cuando muchos usuarios utilizan el sistema simultáneamente. |
| AC02 | Disponibilidad | El sistema debe mantenerse disponible durante la campaña para que los usuarios puedan consultar productos y realizar sus operaciones de compra. |
| AC03 | Escalabilidad | El sistema debe permitir atender un aumento de usuarios y solicitudes sin una degradación significativa del servicio. |
| AC04 | Seguridad | El sistema debe proteger los datos de los usuarios, sus cuentas y las operaciones de compra frente a accesos no autorizados. |
| AC05 | Mantenibilidad | El sistema debe permitir realizar cambios y correcciones sin afectar innecesariamente otras funcionalidades. |
