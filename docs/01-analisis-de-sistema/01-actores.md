# Actores del Marketplace de productos para mascotas

Los actores representan a las personas y sistemas externos que
interactúan con el Marketplace para realizar acciones o intercambiar
información.

| Actor | ¿Qué necesita realizar? |
|-------|--------------------------|
| Cliente | Buscar productos, consultar su información, agregar productos al carrito, realizar pedidos, efectuar el pago y consultar sus pedidos. |
| Seller | Ofrecer productos, registrar y actualizar productos, consultar sus productos y gestionar la información relacionada con sus ventas. |
| Administrador | Administrar la plataforma. |
| Pasarela de pago | Procesar los pagos de las compras. |
| Servicio de envío | Gestionar la información relacionada con la entrega de pedidos. |
| Servicio de facturación | Generar comprobantes de pago. |
| ERP | Proporcionar información de productos y stock. |
